# Publication kit: WeAdU Shopping feed check (Shopify Community)

Texts for the WeAdU team member who posts by hand. Nothing here is posted automatically.

| File | Content |
| --- | --- |
| `listing-en.md` | Short presentation of the page in English (for the page itself, GitHub, and the post). |
| `listing-fr.md` | The same presentation in French. |
| `post-en.md` | Ask & Offer message: a new topic, and a reply to an existing question. |
| `post-fr.md` | French version, for reference only (the Shopify Community board is in English). |
| `instructions-maricar.md` | Where to post, the Shopify Community rules, and how to handle replies (English and French). |
| `checklist.md` | What has to be done before anything is posted. |

Do not post anything until the WeAdU team confirms the page is online and sends you its public link. Replace `LINK` with that link.

This kit replaces the earlier draft `ask-offer-en.md`.
